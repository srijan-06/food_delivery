# Food Delivery System

This project is a complete **Food Delivery System** built using **JavaScript** (for the frontend), **SQL** (for the database), and a backend API. The system allows users to browse food listings, buy food, sell food, add items to their cart, place orders, and manage their profiles. Additionally, the project includes an admin panel for managing users, food listings, orders, and reviews.

## Key Features:
- **User Authentication:** Sign-up, login, and profile management with email as a fixed identifier.
- **Listings:** Users can view, search, and filter food listings based on location.
- **Sell Food:** Users can list food items for sale, including images, descriptions, and pricing.
- **Cart System:** Add food items to the cart, view the total price (including taxes), and proceed to checkout.
- **Order Processing:** Place an order, update the database, and track order status.
- **Admin Panel:** Admins can manage users, food listings (buy and sell), orders, and reviews.
- **Responsive Design:** Mobile-friendly interface using HTML and CSS, ensuring a smooth user experience.

## Tech Stack:
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js (Express.js) for API routes
- **Database:** MySQL for storing user, food, cart, and order data
- **Authentication:** JWT-based token authentication for admin routes
- **Deployment:** Docker for containerization and deployment

## Installation:
1. Clone this repository.
2. Install dependencies for both frontend and backend.
3. Set up the MySQL database and configure the connection.
4. Run the application locally or deploy using Docker.

## Usage:
- Sign up or log in to the platform to browse food listings and add items to your cart.
- Buy food by placing an order and proceeding through checkout.
- Sell food by listing your items with details such as price, description, and images.
- Admins can access the admin panel to manage the system's content and data.
